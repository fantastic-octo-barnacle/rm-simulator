# Title background

`background.png` is a 1280 × 720 game capture of the default RMUC 2026 field
and the procedural stadium. It contains no gameplay HUD. The title UI darkens
and crops the image to fill the window, preserving its aspect ratio.

Capture pose: FLU `(12, -10, 7)` metres, yaw 140°, pitch -22°, free camera,
paused. Hide UI nodes while capturing. The field package is external; no CAD
mesh is embedded in this asset.
